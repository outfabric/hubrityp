Chama seed-default-templates internamente. Retorna success. Se falha na verificação, retorna ActionError "Código incorreto"
- [x] 6.3 Criar `src/modules/whatsapp/server/get-whatsapp-account.ts` — Server Action que busca whatsapp_accounts por user_id do usuário autenticado. Retorna a row ou null se não existe

- [x] 6.5 Criar `src/modules/whatsapp/server/health-check-whatsapp.ts` — Server Action que: autentica via session, busca conta do user, se status='disconnected' retorna early sem chamar Twilio.
